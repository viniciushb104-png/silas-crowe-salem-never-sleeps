# Silas Crowe: Salem Never Sleeps 🎷🦇

**Gothic jazz detective adventure set in supernatural Salem.**

Uma aventura narrativa de investigação híbrida: exploração lateral 2D, análise de cenas point-and-click, interrogatórios, dedução e enigmas musicais.

> “Os mortos não mentem menos que os vivos. Apenas tiveram mais tempo para ensaiar.” — Silas Crowe

## Conceito

Silas Crowe, o Anjo de Salem, é um cantor, radialista e investigador sobrenatural. Uma transmissão inexplicável às 3h13 dá início a um mistério que conecta o presente de uma Salem fictícia às memórias dos julgamentos de 1692–1693.

### Pilares

- Investigações baseadas em pistas e raciocínio.
- Exploração 2D com exame detalhado de objetos.
- Diálogos com consequências e apresentação de evidências.
- Jazz noir, swing e música como parte dos enigmas.
- Humor macabro com respeito à história e às vítimas reais.

## Primeiro protótipo: Arquivo 001 — A Voz das 3h13

**Meta:** 20–30 minutos de jogo.

**Cenários:** clube de jazz, estúdio de rádio e rua de Salem.

**Fluxo:** explorar → reunir pistas → interrogar Edgar → resolver a Ressonância dos Ecos → conectar evidências → concluir o caso.

## Compromisso histórico

Este é um universo sobrenatural **ficcional**. Fatos documentados, interpretações históricas e invenções narrativas serão claramente distinguidos. O humor não tratará as vítimas dos julgamentos como objetos de escárnio.
