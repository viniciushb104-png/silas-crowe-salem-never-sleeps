# Silas Crowe — Idle 360°

Upload the 16 PNG files from Lotes 01 and 02 into this directory. Names follow `silas-idle-<direction>-<frame>.png`, directions: front, front-right, right, back-right, back, back-left, left, front-left; frames: 01 and 02.

The `salem-25d.html` game preloads these files, uses the corresponding direction based on player movement and briefly displays frame 02 in idle animation. If a PNG is missing, a legacy procedural drawing is shown instead; please keep all 16 PNGs in this folder.
